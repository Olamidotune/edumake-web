## 🚀 Getting Started

### Prerequisites

- Flutter (3.0 or higher)
- Dart SDK
- Android Studio / Xcode
- Git

### Installation

1. Clone the repository
```bash
git clone https://github.com/Alphaco-Business-Solutions/edumake-frontend.git
```

2. Navigate to project directory
```bash
cd edumake_frontend
```

3. Install dependencies
```bash
flutter pub get
```

4. Run the app
```bash
flutter run
```

## 🛠️ Technical Architecture
